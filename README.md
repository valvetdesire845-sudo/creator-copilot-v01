# Creator Copilot v0.1
Mobile-first React + Vite prototype. No external backend or AI API is required. AI processing is simulated for product validation.

## Run locally
1. Install Node.js 20+.
2. In this folder run `npm install`.
3. Run `npm run dev`.
4. Open the shown local URL on Safari/Chrome.

## Deploy
This project is ready for Vercel/Netlify/GitHub Pages style deployment. Build command: `npm run build`. Output directory: `dist`.
